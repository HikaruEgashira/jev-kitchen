# CanvasとGPUレンダラーの寿命を揃える

採用。HMRでCanvasが再生成された際、保持されたWebGPUレンダラーが削除済みのCanvasへ描画し続け、HTMLラベル以外の厨房が消えた。

同じCanvasの初期化要求だけを共有する。Canvasが替わったら旧世代を無効化してレンダラーを破棄し、新しい描画先で初期化する。旧世代の非同期完了とdevice lossは新しい画面を変更できない。

READYの登場演出はシーンの経過時間で進め、全パーツの着地後に開店を許可する。ゲーム内の残り時間は消費せず、動きを減らす設定では即座に配置する。

描画はWebGPUに限定する。Three r186がコンストラクタで設定するWebGLフォールバックも無効にし、WebGPU初期化に失敗したら起動案内を表示する。

再現手順はプレイ中に `touch src/Kitchen.jsx` を実行すること。修正前はレンダラーのCanvasがDOMから外れ、修正後は更新を繰り返しても表示中のCanvasと一致する。
