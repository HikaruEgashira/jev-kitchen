# 育成薬で1人ずつ基礎能力を上げる

## 決定

開店準備でコインを使い、対象を1人だけ選んで基礎能力を1段階上げる消耗品（育成薬）を導入する。対象はプレイヤーと雇用済みの従業員全員。効果は選んだキャラクターだけに固定し、レベルやセーブをまたいで保持する。

育成薬は`src/training.js`の`VITAMINS`を唯一の正とする。移動速度の`move`と調理時間の`cook`の2種類で、価格は設備と同じ`investmentCost`基準、1段階あたり移動+4%・調理-4%、各能力5段階まで。購入と対象選択は設備投資と同じく開店準備の請求へ積み、採用・仕入れ・給与・設備投資と一括で検証・確定する。

効果は`src/model.js`の`cookDuration`／`chopDuration`と`src/game.js`の移動stepに`trainingMultiplier`として掛かる。従業員の`STAFF`プロファイルと設備の`equipmentDurationMultiplier`はそのまま残し、育成はその上へ合成する。観測`observe`とcheckpointにも`training`を含める。

## 理由と境界

設備・採用は厨房全体の底上げであり、個々のキャラクターを育てる余地がなかった。料理人を採用しても移動や調理の速さは固定で、誰を伸ばすかという判断が生まれない。対象を1人に絞った消耗品にすることで、プレイヤー自身と相棒のどちらへ投資するかを毎営業選ばせる。

対象選択は購入と同じ開店準備に置く。営業中に能力を増減させる操作は設けない。基礎値の再配分（リセット）や無料の振り直しも扱わない。購入・対象・段階はcheckpointの`training`へ保存し、再挑戦・開店準備への巻戻し・前ステージへの巻戻し・再読込で同じ状態へ復元する。

効果量・価格・上限は`src/training.js`に集約し、Lv1〜100の個別設定表を作らない。育成は採用・設備と同じ財布を共有し、支払い能力を超える購入は確定させない。チェックポイントの版は`training`の追加に合わせて3へ上げ、旧版には空の育成状態を補完する。

## 非採用

全キャラ共通の移動・調理バフ、営業中の一時強化、能力のリセット、クラウド同期は導入しない。従業員ごとの既存プロファイルを置き換えず、加算的な育成に限定する。
